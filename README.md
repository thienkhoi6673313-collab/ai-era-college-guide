## 内容架构（从工具到创造者）

1. **认知**（第1–2章）：任务重新定价；验证与分工框架
2. **工具**（第3–4章）：提问的艺术；把模型组织成学习系统
3. **创造**（第5–6章）：学科边界；从使用者到创造者的身份转换（三种资本/可验证性设计）
4. **规则**（第7–8章）：学术合规；组织采用曲线与职业区分度
5. **人**（第9–10章）：注意力与边界；使用者伦理到创造者伦理
