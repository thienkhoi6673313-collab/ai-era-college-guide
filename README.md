# 与AI共生：AI时代大学生的生成指南

一本面向大学生群体的非虚构书稿项目，目标篇幅 20 万字以上。

## 文件结构

```
AGENTS.md           Codex CLI 项目指令（写作规范、任务总表、验收标准）
STYLE_EXEMPLAR.md   文风基准样本（全书唯一文风权威参照）
PROMPTS.md          Task 0–11 逐章写作提示词 + 续写/重写通用指令
manuscript/         书稿正文
  00-前言.md … 11-后记.md
  appendix/         工具速查表、提示词模板库、政策查询指南、延伸阅读、术语词典
```

## 生成方式

使用 Codex CLI，逐章执行 `PROMPTS.md` 中的 Task 0 → Task 11，每章一个 md 文件，完成后按 `AGENTS.md` 的质量验收标准自检并提交。
