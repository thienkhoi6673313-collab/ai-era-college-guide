# 附录E　术语词典（简编版，60条）

> 本词典收录 60 个核心术语，按主题分为六组：基础概念、架构与原理、训练与优化、使用与交互、应用与生态、社会与治理。每条解释以准确为先、通俗为辅，追求 30–80 字内说清"是什么"，不展开争议与论证（正文各章已处理）。完整版计划扩充至约 200 条，增补交叉引用与英文对照。

## 一、基础概念

| 词条 | 解释 |
|---|---|
| 人工智能（AI） | 让机器执行通常需要人类智能才能完成的任务的学科总称，包括推理、感知、语言理解等，不特指某种具体技术。 |
| 机器学习 | 人工智能的一个分支，让系统从数据中自动习得规律而非依赖人工编写的规则，是当代AI的主流实现方式。 |
| 深度学习 | 使用多层神经网络的机器学习方法，2012年后成为主流，大语言模型即由深度学习技术训练而来。 |
| 神经网络 | 一种受人脑结构启发的计算模型，由大量简单计算单元分层连接构成，通过调整连接强度来学习模式。"神经网络"之名只是隐喻，其结构与真实大脑差别很大。 |
| 生成式人工智能 | 以生成新内容（文本、图像、音频等）而非仅做分类或预测为目标的AI系统，ChatGPT等均属此类。 |
| 大语言模型（LLM） | 在海量文本上训练的超大规模语言模型，能理解并生成自然语言，是当前生成式AI的核心形态。 |
| 多模态 | 指模型能同时处理多种类型的信息（文本、图像、音频、视频），并在不同模态之间转换与关联。 |
| 通用人工智能（AGI） | 设想中能在几乎所有认知任务上达到或超过人类水平的AI，目前尚不存在，属于研究目标而非现实。 |
| 算力 | 计算资源的能力总量，通常以芯片数量与性能衡量，是训练大模型的核心成本，常被称为"AI时代的电力"。 |
| 图灵测试 | 图灵于1950年提出的机器智能判据：若人在对话中无法分辨对方是机器还是人，则可认为机器具备智能。它把"机器能否思考"的哲学争论转化为可操作的测试问题。 |

## 二、架构与原理

| 词条 | 解释 |
|---|---|
| Transformer | 2017年提出的神经网络架构，靠注意力机制处理序列数据，是几乎所有大语言模型的基础结构。 |
| 注意力机制 | 让模型在处理每个词时动态关注输入中其他相关部分的技术，是理解上下文依赖关系的关键机制。 |
| 参数量 | 模型中可调节的数值总量，常用"参数规模"衡量模型大小，如千亿参数级模型；参数多不必然更强。 |
| 嵌入（向量表示） | 把词、句子或图像转化为数字向量的技术，语义相近的内容在向量空间中距离更近，是机器"理解"语义的基础。 |
| 上下文窗口 | 模型单次对话能"看到"的文本长度上限，超出部分不再影响输出，长文档处理能力直接受其限制。 |
| 知识截止日期 | 模型训练数据的时间边界，此后的新事件模型并不知晓，回答近期问题时可能出错或编造。 |
| 温度参数 | 控制输出随机性的设置：温度低则回答稳定保守，温度高则更多样但更易跑偏。写代码与事实性问答宜低，找灵感与头脑风暴可高。
| 扩散模型 | 当前主流图像生成技术：先给图像加噪声再学习逆向去噪，逐步从随机噪声中"还原"出符合描述的图像。 |
| 缩放定律 | 经验发现：模型性能随参数、数据与算力的增加而可预测地提升，这一规律驱动了近年模型规模的竞赛。 |
| 涌现能力 | 模型规模跨过某个阈值后突然出现的小模型不具备的能力（如复杂推理），其成因与真实性仍有学术争议。 |

## 三、训练与优化

| 词条 | 解释 |
|---|---|
| 训练数据 | 用于教模型学习的一切材料，其规模与质量决定模型的"见识"；训练数据中的偏见与错误会进入模型行为。 |
| 预训练 | 模型学习的第一阶段：在海量无标注文本上学习语言的统计规律，耗资巨大，是大模型成本的绝对大头。 |
| 微调 | 在预训练模型基础上，用较小的针对性数据继续训练，使模型适应特定任务或风格，成本远低于从头训练。 |
| 指令微调 | 用"指令—回答"格式的数据训练模型学会听从人类指令，是把一个"续写机器"变成"对话助手"的关键步骤。 |
| 强化学习 | 让智能体通过试错与奖励反馈学习策略的方法，围棋程序AlphaGo与大模型的"偏好对齐"都用到了它。 |
| 人类反馈强化学习（RLHF） | 让人类对模型的多个回答排序打分，再用这些偏好数据训练模型，使其输出更符合人类期望。 |
| 对齐 | 让模型的目标与人类意图、价值观保持一致的技术与过程，"对齐问题"也指强大系统难以确保可控的深层难题。 |
| LoRA | 一种低成本的微调技术：冻结原模型、只训练少量附加参数，使个人与小机构也能定制模型。 |
| 知识蒸馏 | 让小模型模仿大模型的输出从而获得接近能力的技术，是许多"轻量版"模型的来源。 |
| 量化 | 降低模型数值精度以压缩体积、降低部署成本的技术，代价通常是能力的小幅下降。 |

## 四、使用与交互

| 词条 | 解释 |
|---|---|
| 提示词（Prompt） | 用户输入给模型的指令与上下文，是影响输出质量的最直接变量，本书第三章即讨论其写作方法。 |
| 系统提示词 | 对话开始前设定的、通常对用户不可见的指令，规定模型的角色、边界与行为方式。 |
| 角色设定 | 在提示词中为模型指定身份（如"你是出题老师"），用于激活特定知识视角与表达风格。 |
| 少样本提示 | 在提示词中给出若干示例让模型模仿，比纯指令描述更可靠，适合格式或风格有明确要求的任务；示例质量直接决定输出质量。 |
| 思维链（CoT） | 要求模型"一步步推理再给答案"的技巧，在数学与逻辑任务上能显著提升正确率。 |
| 多轮对话 | 通过连续追问逐步修正输出的交互方式；好结果通常来自多轮收敛而非一次完美的提问。 |
| 幻觉 | 模型以流畅、自信的语气输出虚构内容（如不存在的文献、编造的数据）的现象，是使用AI的首要风险。 |
| 护栏 | 开发者施加于模型的内容与行为限制，防止违规输出；过严的护栏也会导致不必要的拒绝。 |
| 水印 | 嵌入AI生成内容中的可机器识别的标记，用于溯源；现有水印技术的可靠性仍有限。 |
| AI检测工具 | 声称能判断文本是否由AI生成的软件，误判率较高且易被规避，其结果不宜单独作为判定依据。 |

## 五、应用与生态

| 词条 | 解释 |
|---|---|
| API | 应用程序接口，开发者通过它调用模型能力，是AI集成进各类软件的通道；按调用量计费是主要商业形态。 |
| 开源模型 | 公开发布模型权重、可免费下载改造的模型（如Llama系列），与闭源商业模型相对，是本地部署的前提。 |
| 本地部署 | 把模型下载到自己的设备上运行，数据不出本地、隐私更好，但受硬件算力限制，能力通常弱于云端旗舰。 |
| 检索增强生成（RAG） | 让模型回答前先检索外部资料库再基于资料作答，能缓解幻觉、引入新知识，是"让AI查资料再回答"的机制。 |
| 向量数据库 | 专门存储与检索向量表示的数据库，是RAG与个人知识库检索的技术底座。 |
| 智能体（Agent） | 能自主规划步骤、调用工具、完成多步任务的AI系统，从"回答问题"走向"代办事情"的产品形态。 |
| 工具调用 | 模型按需调用外部功能（搜索、计算器、代码执行）的机制，弥补其自身的能力缺口，是智能体完成实际任务的核心组成。 |
| 模型上下文协议（MCP） | 一种让模型与外部工具、数据源标准化连接的开放协议，2024年提出 `[待核实]`，生态仍在形成中。 |
| 文生图 | 以文字描述生成图像的技术与应用，扩散模型是其主流实现，版权与训练数据争议的焦点领域。 |
| 文生视频 | 以文字或图像生成视频片段的技术，当前时长与可控性仍处早期，被普遍视为下一个爆发点 `[待核实]`。 |

## 六、社会与治理

| 词条 | 解释 |
|---|---|
| 深度伪造 | 用AI合成以假乱真的图像、音频或视频，冒充真实人物的技术及其产物，是认识论安全的核心威胁。 |
| 算法偏见 | 训练数据中的社会偏见被模型习得并以"客观"输出的形式固化与放大的现象。 |
| 数字鸿沟 | 不同群体在技术接入、使用能力与受益程度上的差距；AI时代该鸿沟正从"有没有设备"转向"会不会用"。 |
| 认知卸载 | 把本应由自己完成的思考任务转交给外部工具的心理倾向，本书第二章讨论其长期代价。 |
| 数据隐私 | 个人信息被收集、存储与使用的边界问题；与模型的每次对话都是数据贡献，去向取决于服务商政策。 |
| 披露声明 | 在提交成果时如实说明AI参与了哪些环节的书面陈述，是多数"披露型"政策的核心义务。 |
| AI素养 | 理解AI的能力边界、风险机制与使用规范的综合性能力，包括验证输出的习惯与合规意识，正在成为与读写能力并列的基础要求。 |
| AI治理 | 对AI开发与应用进行规范的制度总称，涵盖法律、行业标准与机构内部政策等多个层级。 |
| 生成内容标识 | 对AI生成内容添加显著或隐式标记的制度要求，中国已出台相关规定 `[待核实]`，多国在跟进立法。 |
| 人机协作 | 人与AI在任务中各执一段的分工模式，本书的核心主张是：分工的原则是错误代价与可验证性，而非效率单一维度。 |
